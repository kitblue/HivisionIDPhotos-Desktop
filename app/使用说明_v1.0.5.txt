HivisionIDPhotos 证件照制作工具（桌面版） v1.0.5
=================================================

一、这是什么
  网页版（7860 服务）的功能已完整搬到本地桌面程序里，全部推理在本机完成，
  不联网、不开浏览器、不占用端口。界面已改为现代卡片式风格。

二、怎么用
  1. 双击 HivisionIDPhotos.exe 启动（首次启动约 5-15 秒，属正常）。
  2. 点「选择照片」载入人像照。
  3. 左侧选择：尺寸 / 背景色（含自定义 RGB、HEX、美式背景）/ 渲染方式 /
     抠图与检测模型 / 美颜强度 / 水印 / 相纸排版，右侧实时预览。
  4. 点「开始制作」，完成后在右侧页签切换：标准照、高清照、排版照、
     模板照、运行日志。
  5. 点「保存」写入输出目录，点「打开输出」直接打开文件夹。

三、输出位置
  默认在程序同级目录「照片输出」；若该位置不可写，会自动回退到
  用户图片目录下的 HivisionIDPhotos 文件夹。

四、界面说明
  · 顶栏：选择照片 / 开始制作 / 保存 / 打开输出。
  · 主题切换：窗体最顶端右侧的月亮 ☾ / 太阳 ☀ 图标，点一下即切换
    浅色 / 深色主题，图标随即变成目标主题的形状。
  · 左侧参数区：分组卡片，可鼠标滚轮上下滚动；右侧竖直滚动条有独立
    轨道与滑块配色，深浅主题下都能看清当前位置。
  · 选模型有提示：抠图模型、人脸检测模型的下拉框下方会实时显示当前
    模型的特点（速度、体积、适用场景），方便按需选择。
  · 右侧预览区：五页签。窗口拉伸时，标准照按原比例等比跟随缩放；
    高清照、排版照、模板照会在不裁切、不变形的前提下尽量放大铺满预览区。
  · 底部：进度条与状态提示。

五、注意事项
  · _internal 目录必须和 exe 放在一起，不可单独移动 exe。
  · 多人合照或多格拼图也能直接使用：程序会自动定位画面中最大的人脸并
    裁成单人证件照构图，运行日志会提示「检测到 N 张人脸，已自动聚焦最大人脸」。
  · 若画面里根本没有人脸，或裁剪后仍无法分离出单人主体，会提示更换正脸清晰照片。
  · 整个程序约 780 MB，其中绝大部分是抠图与人脸检测模型（onnx），
    首次启动稍慢属正常，请勿删除 _internal\hivision\creator\weights
    与 _internal\mtcnnruntime\weights 内的模型文件。
  · 若杀毒软件拦截，请将整个程序目录加入信任。
  · 旧界面版本保留在同级 HivisionIDPhotos-EXE-old-v1.0.1-ui 目录，
    历史版本备份在各 HivisionIDPhotos-EXE-bak-* 目录，可随时回退。
