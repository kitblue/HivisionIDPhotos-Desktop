HivisionIDPhotos 证件照制作工具 · Windows 桌面版 v1.0.1
================================================================

一、怎么启动
--------------
1. 把整个 HivisionIDPhotos 文件夹解压到磁盘根目录附近（例如 D:\HivisionIDPhotos），
   路径尽量短、尽量不含中文，避免超出 Windows 260 字符路径限制。
2. 双击「启动.bat」，程序窗口会自动打开。
   · 若窗口没出现，改双击「启动-调试.bat」，控制台里会显示具体错误信息。

不需要安装 Python、不需要联网、不需要下载模型、不打开浏览器。
所有推理都在本机完成，5 个 ONNX 模型已内置在 app\hivision\creator\ 下。

二、能做什么（与网页版一致）
--------------
· 尺寸：尺寸列表（一寸/二寸/小一寸…）/ 只换底 / 自定义像素 / 自定义毫米
· 背景：蓝、白、红、深蓝、浅灰、黑 + 美式证件照 + 自定义 RGB + 自定义 HEX
· 渲染：纯色 / 上下渐变 / 中心渐变
· 排版：六寸、五寸、A4、3R、4R，可选「排版照裁剪线」插件
· 输出：DPI 自定义（默认 300）、目标文件体积（KB 压缩）
· 模型：抠图 hivision_modnet / modnet_photographic / rmbg-1.4 / birefnet-v1-lite（可切换）
        人脸检测 mtcnn / retinaface-resnet50
· 美颜：美白、亮度、对比度、饱和度、锐化（0-5 级）
· 构图：头身比、头顶留白
· 水印：自定义文字 / 颜色 / 字号 / 透明度 / 角度 / 间距
· 插件：人脸旋转对齐、水平翻转、JPEG 格式输出
· 模板照：内置 2 款模板排版

三、产物在哪
--------------
每次点「开始制作」，结果自动保存到：app\照片输出\<时间戳_尺寸>\
  · 标准照_300dpi.png（按设定 KB 压缩）
  · 高清照_300dpi.png
  · 排版照_300dpi.png
  · 模板照1/2_300dpi.png
若程序目录不可写（例如解压到 Program Files），自动改存到：
  用户目录\Pictures\HivisionIDPhotos\

界面右下角「保存当前预览」可单独另存任意一张；「打开输出目录」直接定位文件夹。

四、性能参考（本机 CPU 实测）
--------------
· hivision_modnet + mtcnn：单张 0.6-1.0 秒
· rmbg-1.4：约 2-4 秒
· birefnet-v1-lite：首次加载 7-10 秒，单张约 17-27 秒（画质最好，速度最慢）
首次启动约 1-2 秒完成界面加载，模型按需加载。

五、目录结构
--------------
HivisionIDPhotos\
  ├─ 启动.bat                 主程序入口（无控制台窗口）
  ├─ 启动-调试.bat            排错用，显示控制台日志
  ├─ 使用说明.txt             本文件
  ├─ runtime\                内置 Python 3.11 运行时 + 全部依赖（numpy/opencv/onnxruntime/pillow/mtcnn）
  └─ app\                    程序本体
       ├─ desktop_app.py      桌面版主程序（Tkinter 原生界面）
       ├─ hivision\           上游算法库与 5 个 ONNX 模型
       ├─ demo\               LOCALES 文案、模板资源、示例图片
       ├─ assets\             模板素材
       └─ 照片输出\           结果目录（首次运行自动创建）

七、常见问题
--------------
Q: 双击启动.bat 闪退？
A: 双击「启动-调试.bat」看报错。多数是路径过长（解压到短路径）或杀软拦截 pythonw.exe。

Q: 提示找不到模型 / 推理报错？
A: 确认 app\hivision\creator\weights\ 下 4 个 .onnx 与 app\hivision\creator\retinaface\weights\
   下 1 个 .onnx 都在（合计约 540MB）。

Q: 人脸检测失败？
A: 换「人脸检测模型」为 retinaface-resnet50 再试；单人正脸效果最好。
